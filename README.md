# QA Automation Portfolio

## Цель направления

Продемонстрировать навыки автоматизации API-, UI- и мобильного тестирования.

## Что реализовано лично

- модульные и параметризованные тесты JUnit и TestNG;
- API-тесты на OkHttp, REST Assured и Retrofit;
- UI-тесты с Page Object, Selenide и Cucumber;
- инструментальные Android-тесты Espresso.

## Использованные инструменты

Java, Kotlin, Gradle, JUnit, TestNG, REST Assured, Retrofit, Selenide, Cucumber, Allure, Android Studio и Espresso.

## Полученный результат

Сформированы четыре самостоятельных проекта автоматизации с исходным кодом, тестами и конфигурацией сборки.

## Запуск и просмотр

Перейти в каталог выбранного проекта и выполнить указанную в его README команду Gradle Wrapper.
