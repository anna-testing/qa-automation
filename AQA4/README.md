# Автоматизация тестирования Android

## Цель проекта

Проверить навигацию, интерфейс и системные взаимодействия Android-приложения инструментальными тестами.

## Что реализовано лично

Самостоятельно выполнена практическая часть проекта:

- реализованы Espresso-проверки элементов интерфейса;
- добавлены тесты переходов, toolbar, toast и intent;
- подготовлен Android-проект для запуска на эмуляторе.

## Использованные инструменты

Android Studio, Kotlin, Java, Gradle, Espresso, AndroidX Test.

## Полученный результат

В каталоге `src` сохранено: 7 Java-файлов, 4 Kotlin-файлов. Эти материалы подтверждают выполненную работу.

## Запуск и просмотр

Открыть каталог `src` в Android Studio, запустить эмулятор и выполнить `./gradlew connectedAndroidTest`.
