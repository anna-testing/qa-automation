# Автоматизация тестирования: JUnit и TestNG

## Цель проекта

Реализовать модульные и параметризованные тесты Java-кода с разными фреймворками.

## Что реализовано лично

Самостоятельно выполнена практическая часть проекта:

- созданы проверки валидатора возраста и имени;
- реализованы тесты палиндромов и обработка исключений;
- настроены тестовые наборы JUnit и TestNG.

## Использованные инструменты

Java 21, Gradle, JUnit 5, TestNG, AssertJ.

## Полученный результат

В каталоге `src` сохранено: 14 Java-файлов. Эти материалы подтверждают выполненную работу.

## Запуск и просмотр

Выполнить `./gradlew test` для JUnit или `./gradlew testNG` для TestNG из каталога проекта.
