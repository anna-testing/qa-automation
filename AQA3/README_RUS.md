# Автоматизация UI-тестирования

## Цель проекта

Автоматизировать основные пользовательские сценарии интернет-магазина и сформировать отчётность.

## Что реализовано лично

Самостоятельно выполнена практическая часть проекта:

- реализованы Page Object-классы для авторизации, каталога, корзины и оформления заказа;
- созданы UI-тесты и Gherkin-сценарии;
- подключены Cucumber и Allure, добавлены диагностические материалы.

## Использованные инструменты

Java, Gradle, Selenide, JUnit 5, Cucumber, Allure.

## Полученный результат

В каталоге `src` сохранено: 2 Markdown-документов, 18 Java-файлов. Эти материалы подтверждают выполненную работу.

## Запуск и просмотр

Перейти в `src`, выполнить `./gradlew test`; параметры браузера задать в `gradle.properties`.
