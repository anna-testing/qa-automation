# Автоматизация тестирования REST API

## Цель проекта

Реализовать API-тесты одного сервиса тремя Java-инструментами и сравнить подходы.

## Что реализовано лично

Самостоятельно выполнена практическая часть проекта:

- созданы позитивные и негативные HTTP-проверки;
- реализованы DTO и Java records для сериализации;
- подготовлены независимые наборы тестов на OkHttp, REST Assured и Retrofit.

## Использованные инструменты

Java 21, Gradle, JUnit 5, OkHttp, REST Assured, Retrofit, Jackson, Gson.

## Полученный результат

В каталоге `src` сохранено: 19 Java-файлов. Эти материалы подтверждают выполненную работу.

## Запуск и просмотр

Выполнить `./gradlew test` из каталога проекта; для запуска требуется доступ к тестируемому API.
